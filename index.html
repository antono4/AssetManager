Quick Start

Run locally in 2 commands

Mode Demo (SQLite — no MySQL needed)

git clone https://github.com/antono4/AssetManager.git cd AssetManager/asset_app php -S 0.0.0.0:8080 -t public public/index.php

Open http://localhost:8080 → login admin / admin123

ℹ️ Note: This is a PHP application. GitHub Pages only hosts static files and cannot run PHP. To use the full app, run it locally with PHP or deploy to a PHP-enabled hosting (Apache/Nginx/Docker). See INSTALL.md for details.
